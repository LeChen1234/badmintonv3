# 标注系统生产落地清单

## 已具备

- 前后端真实本地启动、隔离测试数据库和健康/就绪探针。
- 可版本化标注分类配置，前后端共享，服务端拒绝规范外标签。
- 学生任务归属校验、锁定任务写保护、审核状态专用接口。
- 生产环境强制密钥与初始管理员密码，禁止默认凭据静默上线。
- 导出路径封闭、SQLite 外键/WAL、自动备份和全新数据库迁移验证。
- 信息论/微积分/DCT/泛函筛帧，以及可解释的人工复核优先级。

## 上线前必须完成（P0）

- 用 HTTPS 反向代理或内网网关部署，密钥接入正式 Secrets Manager。
- 将 SQLite 切换为 PostgreSQL；多人并发标注不能长期依赖单机数据库。
- 将视频处理和模型推理迁移到持久任务队列，支持重试、幂等和死信处理。
- 增加上传大小/时长/像素限制、文件内容检测、配额与磁盘水位告警。
- 完成备份恢复演练，而不只是验证“能生成备份文件”。
- 建立受试者授权、隐私脱敏、数据许可和删除请求流程。
- 增加 API 集成测试和浏览器端端到端测试，并接入 CI 阻断发布。

## 数据集与论文闭环（P1）

- 每条标注保存 taxonomy、算法、模型、参数和数据版本，保证可追溯。
- 保存“算法建议 → 人工修改 → 专家结论”的差异，用于校准和再训练。
- 建立双人/多人重复标注及 Cohen/Fleiss Kappa、ICC 等一致性指标。
- 数据集按运动员、场次和采集来源分组切分，避免同一人的相邻帧泄漏到测试集。
- 对运动、熵、DCT、calculus 四项评分做消融，并校准复核优先级。
- 建立数据版本、数据卡、模型卡、基准配置和可复现实验清单。

## 运维与治理（P1）

- 接入结构化日志、错误追踪、指标监控和告警；记录请求 ID 与任务 ID。
- 审计日志改为追加写、不可由普通业务事务覆盖，并配置保存期限。
- 配置角色最小权限、管理员 MFA/统一身份认证和账户锁定策略。
- 制定 taxonomy 变更审批与向后兼容策略；已锁定数据不得被新规范静默改写。
