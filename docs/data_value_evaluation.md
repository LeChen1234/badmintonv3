# 数据价值分层评价

系统将四类概念分开记录：

1. **低成本难度**：有动作阶段标签时使用小模型监督损失；没有阶段标签时仅使用预测熵等无标签难度代理。
2. **质量风险**：标签冲突、时序跳变、重复度等复核信号。高风险不自动删除。
3. **目标模型证据**：真实目标模型 loss、由真实分布计算的 loss、经配对样本校准的代理、未校准代理四级来源。
4. **数据价值证据**：只有受控增量训练得到的验证性能变化才称为观测价值；其他分数均称为价值假设。

## 数据写入约定

目标模型的单样本 loss 可写入标注的 `assist_metadata.teacher_loss`。目标模型完整分布仍使用：

```json
{"teacher_distribution": {"preparation": 0.05, "contact": 0.85}}
```

受控增量训练得到的数据价值写入对应帧的：

```json
{"observed_value_gain": 0.0062}
```

其中 `observed_value_gain` 必须是在固定模型、训练设置和独立验证集下得到的性能变化，不能用训练 loss 代替。

## 接口

`GET /tasks/{batch_id}/data-value-report`

返回每条标注的难度、质量风险、目标模型证据、单位成本价值假设、决策建议和证据等级。批次摘要用于比较采集形式，但在没有真实增量训练结果时只展示为实验性代理。

## 使用边界

- 高 loss 不等于高价值。
- 高熵困难样本不等于坏数据。
- 单帧价值不能直接相加为视频价值。
- 视频和比赛必须分组划分，禁止相邻帧跨训练集与测试集。
- 未校准代理不能作为自动删除或正式数据发布依据。
