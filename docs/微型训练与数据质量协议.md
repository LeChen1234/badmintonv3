# 微型训练与数据质量协议

本协议用于快速判断“新标注流程产生的数据是否真的更有训练价值”，不把线性探针结果包装成最终模型性能。

## 1. 数据冻结与隔离

1. 先由专家建立独立测试集，之后不得用它调 taxonomy、筛帧阈值或辅助算法。
2. 基线数据和新流程数据均只使用已确认、已锁定任务。
3. 训练集与测试集按 `match_uuid` 隔离；脚本默认检测交叉并直接失败。
4. 同一运动员跨场次泄漏仍需在数据清单层面检查，后续正式实验应同时按 `selected_player_uuid` 分组。

## 2. 导出后先执行质量门禁

```powershell
.\.venv\Scripts\python.exe scripts\data_quality_report.py data\exports\new.json `
  --output data\exports\new_quality_report.json
```

门禁覆盖：可训练姿态比例、非法坐标、taxonomy 越界、类别分布、关键点可见率、重复姿态、场次身份、版本溯源、标注耗时和辅助采纳率。`status=fail` 时不进入论文主实验。

## 3. 等预算 A/B 微训练

```powershell
.\.venv\Scripts\python.exe scripts\micro_train_data_probe.py `
  --baseline data\exports\baseline.json `
  --curated data\exports\curated.json `
  --test data\exports\expert_holdout.json `
  --label action_type `
  --repeats 10 `
  --output data\exports\micro_train_report.json
```

脚本默认按类别取基线/新流程两边的最小样本数，确保训练预算相同；报告 Accuracy、Balanced Accuracy、Macro-F1、NLL 和 ECE 的均值与标准差。只有新流程在 Macro-F1/Balanced Accuracy 上提升，同时 NLL/ECE 不明显恶化，才认为数据效用得到初步支持。

`--unequal-budget` 和 `--allow-group-overlap` 仅用于排错，不得用于论文主结果。

微训练完成后，在系统“主动学习闭环”页面登记 dataset ID、模型版本、Macro-F1 均值/标准差、本轮标注人时和各组件消融增益。系统会保存轮次证据、更新下一轮抽帧权重，并根据 `config/research_protocol.json` 中的阈值与 patience 给出继续/停止建议。新上传视频会自动使用该项目最新权重，实际参数随任务和数据导出保存。

## 4. 正式论文实验仍需补齐

- 至少三个随机种子，并报告 bootstrap 置信区间或配对显著性检验。
- 在轻量时序模型和目标主干模型上复验，排除结果只对线性探针成立。
- 做筛帧信息量、复核优先级、辅助采纳三个模块的逐项消融。
- 报告单位有效样本的人时成本、专家修改率和跨标注员一致性，而不只报告最终准确率。
